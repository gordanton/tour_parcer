# Telegram-бот мониторинга акций туроператоров (`tour_parcer`)

Telegram-бот для автоматического сбора горящих туристических предложений и акций с сайтов 6 крупных туроператоров, сохранения в базу данных **SQLite** и удобного просмотра через инлайн-пагинацию.

## Цель и задачи проекта

- **Цель:** Собрать разрозненные страницы акций ведущих туроператоров в единую витрину внутри Telegram, чтобы пользователь или турагент мог просматривать актуальные спецпредложения в одном окне.
- **Ключевые задачи:**
  - реализовать парсеры страниц акций для 6 туроператоров (Coral Travel, Anex Tour, Sunmar, Библио-Глобус, PEGAS Touristik, FUN&SUN);
  - очищать и сохранять собранные карточки предложений в локальную БД SQLite без дублей;
  - разработать интерфейс в Telegram с постраничным перелистыванием (по 10 предложений на экран);
  - добавить административные команды для принудительного обновления базы и просмотра статистики.

## Результаты

- Автоматический сбор и агрегация акций сразу из 6 источников по одной команде.
- Удобная инлайн-пагинация (`◀️ Назад` / `Вперёд ▶️`) без засорения чата длинными списками сообщений.
- Готовая инструкция и конфигурация `systemd` для круглосуточной работы бота на Linux VPS.

## Использованные технологии и библиотеки

- **Язык:** Python 3.10+
- **Telegram-бот:** `pyTelegramBotAPI` (`telebot`)
- **Парсинг веб-страниц:** `requests`, `BeautifulSoup4` (`bs4`)
- **База данных и конфигурация:** `SQLite3`, `python-dotenv`, `logging`

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветственное сообщение и главное меню |
| `/promo` | Вывести первые 10 горящих предложений с кнопками пагинации |
| `/help` | Справка по командам |
| `/update` | Принудительно обновить базу данных со всех сайтов (только для администратора) |
| `/stats` | Показать статистику: количество предложений и пользователей (только для администратора) |

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/gordanton/tour_parcer.git
cd tour_parcer
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate      # Windows
# source venv/bin/activate # Linux / macOS
pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и укажите свои данные:

```env
BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id_числом
DB_NAME=travel_promotions.db
```

4. Запустите бота:

```bash
python bot.py
```

При первом запуске таблицы в SQLite создаются автоматически.

## Структура проекта

```text
├── parser.py           # модули парсинга сайтов туроператоров

```
